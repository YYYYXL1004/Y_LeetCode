# Hot 100 冲刺模板补充设计

## 目标

在 `notes/CSP赛前模板速查.md` 中补充适合预推免机试冲刺的 Hot 100 高频模型，重点覆盖当前模板缺少的常见动态规划、双指针、滑动窗口、区间、拓扑排序和堆。内容应便于纸质打印和快速定位，不追求完整覆盖 Hot 100。

## 范围

新增以下 13 个核心代码框架：

1. 三数之和通用双指针框架。
2. 固定长度滑动窗口。
3. 可变长度滑动窗口。
4. 合并区间。
5. 拓扑排序。
6. Top K 高频元素。
7. 最大子数组和。
8. 乘积最大子数组。
9. 打家劫舍。
10. 网格路径与最小路径和。
11. 零钱兑换最少硬币。
12. 单词拆分。
13. 最长公共子序列。

其中固定长度和可变长度滑动窗口合并在同一个小节，因此文档层面共新增 12 个小节。

本次不补充链表节点操作、二叉树构造、Trie、LRU、并查集变式和高级字符串算法。这些内容要么已有独立笔记，要么不适合当前精简打印版的篇幅目标。

将以下内容加入现有“八、动态规划”章节，并放在背包模板之后、LIS 和编辑距离附近，使同类状态转移集中：

在动态规划章节之后增加“Hot 100 高频模型”章节，包含：

后续原有章节编号顺延，确保标题编号连续。

## 模板写法

每个小节保持统一结构：

1. 用一至三行中文说明识别特征或状态定义。
2. 给出可直接嵌入 ACM `main` 的核心 C++ 代码，不使用 LeetCode `class Solution` 包装。
3. 标出时间和空间复杂度。
4. 用注释强调一个到三个高频易错点，例如初始化、循环方向、去重或边界。

代码沿用仓库现有风格：

- 使用 `#include<bits/stdc++.h>` 对应的 STL 能力，不额外展开头文件列表。
- 使用 `using namespace std;` 的命名环境。
- 使用 `vector`、范围循环和中文行内注释。
- 循环与输入输出保持仓库常见的紧凑写法，例如 `cin>>n>>m`。
- 数值可能溢出时使用 `long long` 或显式说明取值范围。

## 验证

修改完成后执行以下检查：

1. 查看目标文件 Git diff，确认用户原有修改仍然保留，新改动仅为计划内模板和章节编号。
2. 检查 Markdown 围栏数量成对，所有新增小节位于预定章节。
3. 将新增 C++ 核心片段放入最小测试外壳进行语法编译，或对无法独立编译的片段逐段构造等价编译检查。
4. 检查每个新增模板包含识别说明、复杂度和易错点。
5. 搜索标题，确认章节编号连续且不存在重复编号。
