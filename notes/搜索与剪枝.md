# 搜索与剪枝

## DFS + 最优性剪枝（最大剩余资源记忆化）

暴力 DFS 遍历所有可达状态时，大量分支会重复访问同一个状态。普通 `visited` 标记只能防止同一条路径重复访问，但不同路径到达同一状态时无法剪枝。

**核心思想**：用 `memo[state]` 记录到达该状态时的**最大剩余资源**（步数/体力/时间等）。如果当前到达该状态的剩余资源不优于已记录值，则当前分支不可能探索到任何新状态，直接剪枝。

**与普通记忆化搜索的区别**：
- 普通记忆化搜索：缓存 `f(state)` 的返回值，避免重复计算同一子问题
- 最优性剪枝：不缓存返回值，通过比较"当前资源 vs 历史最优资源"截断劣质分支

**适用信号**：从起点出发，有限步数/资源内探索所有可达状态（如棋子移动、迷宫探索），暴力 DFS 超时。

```cpp
vector<vector<int>> memo; // memo[x][y] = 到达(x,y)时的最大剩余步数，初始化 -1

void dfs(int x, int y, int k) {
    if (越界) return;
    if (k <= memo[x][y]) return; // 剪枝：当前不优于历史最优
    memo[x][y] = k;              // 刷新最优状态
    // 标记/统计当前格子
    if (k > 0) {
        for (auto [dx, dy] : directions) {
            dfs(x + dx, y + dy, k - 1);
        }
    }
}
```

**坑点**：
- `memo` 初始化为 **-1** 而非 0：剩余资源 k=0 也是合法到达状态，必须与"未访问"区分
- 顺序：先剪枝检查 → 刷新 memo → 标记格子 → 递归

### 马的可达格子（CSP202506B）

n×n 棋盘上马从起点出发，k 步内能到达的不同格子数。马走日字（8 方向）。

```cpp
vector<vector<int>> mp, memo;
int n, cnt = 0;

void dfs(int x, int y, int k) {
    if(x > n || x < 1 || y < 1 || y > n) return;
    if (k <= memo[x][y]) return;  // 最优性剪枝
    memo[x][y] = k;
    if(mp[x][y] == 0) { mp[x][y] = 1; cnt++; }
    if(k > 0) {
        dfs(x-2, y+1, k-1); dfs(x-1, y+2, k-1);
        dfs(x+1, y+2, k-1); dfs(x+2, y+1, k-1);
        dfs(x-2, y-1, k-1); dfs(x-1, y-2, k-1);
        dfs(x+1, y-2, k-1); dfs(x+2, y-1, k-1);
    }
}
```

暴力 DFS（无 memo 剪枝）只能通过 80%，加上最优性剪枝后满分。
