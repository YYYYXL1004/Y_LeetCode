# 比赛注意事项：精准踩坑清单

> 从 310+ 道刷题中提炼，每一条都对应真实 WA/TLE/MLE 场景。考前 10 分钟过一遍。

---

## 一、I/O 陷阱（送命区）

**1. 快读快写必须写**
```cpp
ios::sync_with_stdio(false);
cin.tie(nullptr);
```
不写这两行，大数据量输入可能 TLE。写了之后不能混用 `scanf/printf`（除非只用 `printf` 输出浮点）。

**2. `cin >> n` 后接 `getline` 必须吃换行**
```cpp
cin >> n;
cin.ignore();  // 或 getchar()
getline(cin, s);
```
否则 `getline` 读到空串。

**3. 用 `"\n"` 不用 `endl`**
`endl` 会 flush 缓冲区，循环中大量使用直接 TLE。

**4. 行末空格处理**
```cpp
for(int i = 0; i < n; i++) {
    if(i) cout << ' ';
    cout << a[i];
}
```

**5. 浮点精度输出**
- `printf("%.6f", x)` 比 `cout << fixed << setprecision(6) << x` 更可靠
- 比较浮点数用 `fabs(a - b) < 1e-9`，不要用 `==`

**5.1 浮点数判零（血泪教训！）**
- **永远不要用 `== 0` 判断浮点数是否为零！** 浮点运算会产生微小误差，`== 0` 几乎永远为 false
- 正确写法：`const double EPS = 1e-7; if(abs(x) <= EPS)` 表示"x 约等于 0"
- C++ 用 `abs()`（`<cmath>`），C 用 `fabs()`；**不要写成 `fabs` 在 C++ 里也能用但 `abs` 更通用**
- 同理，判断 `x == a` 要写成 `abs(x - a) <= EPS`
- 高斯消元、几何计算、浮点二分等场景最容易踩这个坑
- 如果题目允许整数/模运算，优先用模意义下的高斯消元（如模 998244353），彻底规避精度问题

## 二、数据类型（最隐蔽的 WA）

**6. 中间结果溢出：先转再乘**
```cpp
long long c = (long long)a * b;   // 正确
long long c = a * b;              // 错误！乘完已经溢出再赋值
```
看到数据范围 > 2e9 或涉及乘法，立刻用 `long long`。

**7. LCM 先除后乘**
```cpp
long long lcm = a / __gcd(a, b) * b;  // 正确
long long lcm = a * b / __gcd(a, b);  // 溢出
```

**8. `size_t` 是无符号的**
```cpp
s.find("x") < 0          // 永远 false！size_t 无符号
s.find("x") != string::npos  // 正确

v.size() - 1              // 空 vector 时下溢为巨大正数
(int)v.size() - 1         // 竞赛里直接强转最省心
```

## 三、STL 高频坑

**9. `emplace_back` 自定义结构体需要构造函数**
```cpp
struct task {
    double t, a, b;
    task(double t, double a, double b) : t(t), a(a), b(b) {}  // 必须写
};
v.emplace_back(t, a, b);  // 调用构造函数
```
`push_back` 可以用 `{t, a, b}` 聚合初始化，但 `emplace_back` 需要匹配的构造函数。

**10. `priority_queue` 自定义比较器**
```cpp
// lambda 写法（推荐）
auto cmp = [](const pair<int,int>& a, const pair<int,int>& b) {
    return a.second > b.second;
};
priority_queue<pair<int,int>, vector<pair<int,int>>, decltype(cmp)> pq(cmp);
// 注意：decltype(cmp) 作为第三个模板参数，且构造时必须传入 cmp 实例

// 结构体写法
struct State {
    int node, dist;
    bool operator<(const State& other) const {  // const 必须写！
        return dist > other.dist;  // > 让 priority_queue 变成最小堆
    }
};
```

**11. `stack`/`queue` 的 `pop()` 不返回值**
```cpp
int x = st.top(); st.pop();   // 正确
int x = st.pop();              // 错误！pop 返回 void
```

**12. `map` 下标访问会自动创建**
```cpp
if(m["key"] == 0)     // 即使不存在也会插入 key=0
if(m.count("key"))    // 正确：只检查不创建
```

**13. 遍历时删除迭代器**
```cpp
// vector: erase 返回下一个有效迭代器
for(auto it = v.begin(); it != v.end(); ) {
    if(条件) it = v.erase(it);  // erase 返回下一个
    else ++it;
}
```

## 四、算法实现细节

**14. 递归传容器必须传引用**
```cpp
void dfs(int u, vector<int>& path) { ... }  // 正确
void dfs(int u, vector<int> path) { ... }   // 每次递归复制整个容器，TLE+MLE
```

**15. 0/1 背包必须倒序遍历**
```cpp
for(int j = T; j >= t[i]; j--)    // 正确：倒序保证每个物品只用一次
for(int j = t[i]; j <= T; j++)    // 错误：变成完全背包
```

**16. Floyd 中间节点 INF 检查**
```cpp
for(int k = 0; k < n; k++)
    for(int i = 0; i < n; i++) {
        if(dist[i][k] == INF) continue;  // 不加这行会溢出！
        for(int j = 0; j < n; j++)
            dist[i][j] = min(dist[i][j], dist[i][k] + dist[k][j]);
    }
```

**17. Dijkstra 弹出时剪枝**
```cpp
auto [d, u] = pq.top(); pq.pop();
if(d > dist[u]) continue;  // 跳过过时记录，没有这行会 TLE
```

**18. 单调栈/单调队列存下标不存值**
存下标才能判断元素是否过期（滑动窗口）或计算距离（如"下一个更大元素"）。

**19. 网格 BFS 方向数组**
```cpp
int dx[] = {-1, 1, 0, 0};
int dy[] = {0, 0, -1, 1};
// 边界检查：0 <= nx < n && 0 <= ny < m
// 加哨兵边界可省去每次检查：开 (n+2)*(m+2) 数组，外围填特殊值
```

**20. INF 值选择**
```cpp
const int INF = 0x3f3f3f3f;  // 约 10^9，两个 INF 相加不溢出
// 不要用 INT_MAX (0x7fffffff)，两个 INT_MAX 相加会溢出变成负数
```

## 五、输出格式（格式错误直接 0 分）

**21. 前导零**
```cpp
printf("%05d", id);  // 天梯赛链表题、学号题必考
```

**22. `-1` 不补零**
```cpp
if(next == -1) printf("%05d %d -1\n", addr, val);  // -1 不要写成 %05d
```

**23. 浮点输出位数**
题目要求保留 2 位就 2 位，保留 6 位就 6 位，多/少都可能判错。
