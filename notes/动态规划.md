# 动态规划

## DP 核心要素
1. **状态定义**：确定 dp 数组/函数的含义，找出变化的变量
2. **选择**：导致状态变化的行为
3. **状态转移方程**：dp[i] 与 dp[i-1] 等之间的关系
4. **base case**：初始条件/边界情况

## 两种实现方式

### 1. 备忘录递归（自顶向下）
- 从目标状态开始，递归求解子问题
- 用备忘录避免重复计算

### 2. DP table 迭代（自底向上）
- 从小问题开始，逐步推导出大问题的解
- 通常更高效，无递归栈开销

## 斐波那契数（509）
**状态转移**：`dp[i] = dp[i-1] + dp[i-2]`

### 方法一：备忘录递归（自顶向下）
```cpp
class Solution {
public:
    vector<int> memo;
    
    int fib(int n) {
        memo = vector<int>(n + 1, -1);  // 初始化为特殊值表示未计算
        return dp(n);
    }
    
    int dp(int n) {
        // base case
        if(n == 0 || n == 1) return n;
        // 查备忘录，避免重复计算
        if(memo[n] != -1) return memo[n];
        // 存入备忘录
        memo[n] = dp(n - 1) + dp(n - 2);
        return memo[n];
    }
};
```

### 方法二：迭代解法（自底向上）
```cpp
int fib(int n) {
    if(n == 0 || n == 1) return n;
    vector<int> dp(n + 1);
    dp[0] = 0, dp[1] = 1;
    for(int i = 2; i <= n; i++) {
        dp[i] = dp[i - 1] + dp[i - 2];
    }
    return dp[n];
}
```

## 零钱兑换（322）
**完全背包问题**：硬币数量无限，求凑出金额的最少硬币数

**状态定义**：`dp[i]` 表示凑出金额 i 所需的最少硬币数

**状态转移**：`dp[i] = min(dp[i], dp[i - coin] + 1)`，对所有 coin 遍历

### 方法一：备忘录递归（自顶向下）
```cpp
class Solution {
public:
    vector<int> memo;
    
    int coinChange(vector<int>& coins, int amount) {
        memo = vector<int>(amount + 1, -666);  // 特殊值表示未计算
        return dp(coins, amount);
    }
    
    // 定义：凑出金额 amount，至少需要 dp(coins, amount) 个硬币
    int dp(vector<int>& coins, int amount) {
        if(amount == 0) return 0;
        if(amount < 0) return -1;
        // 查备忘录
        if(memo[amount] != -666) return memo[amount];
        
        int res = INT_MAX;
        for(int coin : coins) {
            int sub = dp(coins, amount - coin);  // 子问题
            if(sub == -1) continue;  // 子问题无解，跳过
            res = min(res, sub + 1);
        }
        // 存入备忘录
        memo[amount] = (res == INT_MAX) ? -1 : res;
        return memo[amount];
    }
};
```

### 方法二：迭代解法（自底向上）
```cpp
int coinChange(vector<int>& coins, int amount) {
    // 初始化为 amount + 1（不可能的最大值）
    vector<int> dp(amount + 1, amount + 1);
    dp[0] = 0;  // 凑出金额0需要0个硬币
    
    for(int i = 1; i <= amount; i++) {
        for(int coin : coins) {
            if(i - coin < 0) continue;  // 子问题无解
            dp[i] = min(dp[i], dp[i - coin] + 1);
        }
    }
    return (dp[amount] == amount + 1) ? -1 : dp[amount];
}
```

## 最长递增子序列（300）

### 方法一：DP 解法 O(n²)
**状态定义**：`dp[i]` 表示以 `nums[i]` 结尾的最长递增子序列的长度

**状态转移**：`dp[i] = max(dp[i], dp[j] + 1)`，其中 `j < i` 且 `nums[j] < nums[i]`

```cpp
int lengthOfLIS(vector<int>& nums) {
    vector<int> dp(nums.size(), 1);  // 每个元素本身就是一个长度为1的递增子序列
    for(int i = 0; i < nums.size(); i++) {
        for(int j = 0; j < i; j++) {
            if(nums[i] > nums[j]) {
                dp[i] = max(dp[i], dp[j] + 1);
            }
        }
    }
    // 结果是 dp 数组中的最大值
    int res = 0;
    for(int i = 0; i < dp.size(); i++) {
        res = max(res, dp[i]);
    }
    return res;
}
```

### 方法二：贪心 + 二分优化 O(n log n)
**核心思想**：对于相同长度的递增子序列，我们总是希望结尾元素越小越好，这样更利于后续元素接在后面。

**维护 `tail` 数组**：`tail[i]` 表示长度为 `i+1` 的递增子序列的最小结尾元素

```cpp
int lengthOfLIS(vector<int>& nums) {
    vector<int> tail;
    tail.push_back(nums[0]);
    
    for(int i = 1; i < nums.size(); i++) {
        if(nums[i] > tail.back()) {
            // 当前元素大于 tail 最后一个元素，直接扩展
            tail.push_back(nums[i]);
        } else {
            // 否则，找到 tail 中第一个 >= nums[i] 的位置并替换
            int pos = lower_bound(tail.begin(), tail.end(), nums[i]) - tail.begin();
            tail[pos] = nums[i];
        }
    }
    return tail.size();
}
```

## 俄罗斯套娃信封问题（354）

**问题转化**：将二维问题转化为一维的 LIS 问题

**关键步骤**：
1. **排序**：按宽度升序排列，宽度相同时按高度**降序**排列
   - 宽度相同时高度降序是为了避免同一宽度的信封被同时选中
2. **求 LIS**：对高度数组求最长递增子序列

```cpp
int maxEnvelopes(vector<vector<int>>& envelopes) {
    // 按宽度升序，宽度相同按高度降序
    sort(envelopes.begin(), envelopes.end(), [](auto& a, auto& b) {
        return a[0] == b[0] ? b[1] < a[1] : a[0] < b[0];
    });
    
    // 提取高度数组
    vector<int> height;
    for(auto& e : envelopes) height.push_back(e[1]);
    
    // 求高度的 LIS（使用贪心+二分优化）
    return lengthOfLIS(height);
}
```

## 规划兼职工作（1235）
- 按结束时间排序 + DP + 二分查找优化
- `dp[i]` 表示考虑前 i 个工作的最大收益
- 转移时二分查找不冲突的上一个工作
- 使用 `upper_bound` 找第一个结束时间 > 当前开始时间的位置，其前一个即为合法状态
  ```cpp
  // 按结束时间排序，提取 ends 数组用于二分
  for(int i = 1; i <= n; i++) {
      int currStart = jobs[i-1][0], currProfit = jobs[i-1][2];
      // 在 ends 的前 i-1 个元素中找第一个 > currStart 的位置
      auto it = upper_bound(ends.begin(), ends.begin() + i - 1, currStart);
      int prevIdx = distance(ends.begin(), it);
      // dp 是 1-based，ends 是 0-based，distance 刚好对应 dp 中上一个合法状态
      dp[i] = max(dp[i-1], dp[prevIdx] + currProfit);
  }
  ```

## 题型模板：0-1 背包
**适用信号**：给定 n 个物品，每个物品只能选或不选，求能否/最多/最少凑出某个容量

**通用步骤**：
1. 计算总和/目标值，做可行性剪枝
2. 定义 `dp[j]`：能否（或最优值）凑出容量 j
3. 外层遍历物品，**内层倒序遍历容量**（保证每个物品只用一次）
4. 状态转移：`dp[j] = dp[j] || dp[j - w[i]]`（判定型）或 `dp[j] = max(dp[j], dp[j - w[i]] + v[i])`（最值型）

**复杂度**：O(n * target) 时间，O(target) 空间

**通用坑点**：
- 内层**必须倒序**，否则退化为完全背包（物品可重复选）
- 判定型题目可提前 `if(dp[target]) return true` 剪枝
- 总和为奇数时直接返回 false（无法均分）

## 分割等和子集（416）
**问题转化**：能否分成两个等和子集 → 能否选出若干数使其和为 `sum/2`

### 方法一：一维DP（滚动数组）
```cpp
bool canPartition(vector<int>& nums) {
    int sum = 0;
    for(int num : nums) sum += num;
    if(sum % 2 != 0) return false;
    int target = sum / 2;
    vector<bool> dp(target + 1, false);
    dp[0] = true;
    for(int i = 0; i < nums.size(); i++) {
        for(int j = target; j >= nums[i]; j--) {  // 倒序！
            dp[j] = dp[j] || dp[j - nums[i]];
        }
        if(dp[target]) return true;  // 剪枝
    }
    return dp[target];
}
```

### 方法二：二维DP
```cpp
bool canPartition(vector<int>& nums) {
    int sum = 0;
    for(int num : nums) sum += num;
    if(sum % 2 != 0) return false;
    int n = nums.size(), target = sum / 2;
    vector<vector<bool>> dp(n + 1, vector<bool>(target + 1, false));
    dp[0][0] = true;
    for(int i = 1; i <= n; i++) {
        for(int j = 0; j <= target; j++) {
            if(j < nums[i - 1]) dp[i][j] = dp[i - 1][j];
            else dp[i][j] = dp[i - 1][j] || dp[i - 1][j - nums[i - 1]];
        }
    }
    return dp[n][target];
}
```

## 题型模板：完全背包
**适用信号**：每种物品可无限次使用，求凑出目标的方案数/最值

**与0-1背包的关键区别**：内层**正序**遍历容量（0-1背包必须倒序）

**通用步骤**：
1. 定义 `dp[j]`：凑出容量 j 的方案数（或最优值）
2. 外层遍历物品，**内层正序遍历容量**（允许重复选取同一物品）
3. 状态转移：`dp[j] += dp[j - w[i]]`（计数型）或 `dp[j] = max/min(dp[j], dp[j - w[i]] + v[i])`（最值型）

**二维版本**：`dp[i][j] = dp[i-1][j] + dp[i][j - w[i]]`（不选 + 选了还能再选）

**复杂度**：O(n * target) 时间，O(target) 空间

**排列数 vs 组合数的关键区别**：
- 求**组合数**（如 518）：外层遍历物品、内层正序遍历容量 → `{1,2}` 和 `{2,1}` 算同一种
- 求**排列数**（如 377）：外层遍历容量、内层遍历物品 → `{1,2}` 和 `{2,1}` 算不同种
- 判断方法：如果物品有明确顺序（如台阶编号、硬币面值排列），就是排列；只关心"选了什么"不关心"顺序"，就是组合

**通用坑点**：
- 内层**必须正序**，否则退化为0-1背包（每个物品只用一次）
- 计数型题目中间值可能远超最终答案，注意数据类型溢出

### 完全背包最值型：固定总量拆分取最大收益
**适用信号**：总量固定，可以拆成若干段/若干天/若干次操作，每种拆分长度可重复使用，长度 i 对应收益 `value[i]`。

**标准框架**：
```cpp
vector<int> dp(n + 1, 0);
for (int w = 1; w <= m; w++) {
    for (int j = w; j <= n; j++) {
        dp[j] = max(dp[j], dp[j - w] + value[w]);
    }
}
```

**题目差异（CSP202503B 机器人饲养指南）**：
- 一天投喂 i 个苹果就是重量 i、价值 Ai 的物品，天数不限，所以是完全背包。
- Ai 不保证单调，不能用“每天尽量多投”或“只选单日最大收益”贪心。
- n <= 1e4, m <= 100，O(nm) 正好符合约束。

## 零钱兑换 II（518）
**完全背包计数**：硬币无限，求凑出金额的组合数

**状态定义**：`dp[i][j]` 表示用前 i 种硬币凑出金额 j 的方案数

**状态转移**：`dp[i][j] = dp[i-1][j] + dp[i][j - coins[i-1]]`

### 方法一：二维DP
```cpp
int change(int amount, vector<int>& coins) {
    int n = coins.size();
    vector<vector<unsigned int>> dp(n + 1, vector<unsigned int>(amount + 1, 0));
    for(int i = 0; i <= n; i++) dp[i][0] = 1;  // 凑出金额0只有1种方案
    for(int i = 1; i <= n; i++) {               // 注意是 i <= n
        for(int j = 1; j <= amount; j++) {
            if(j - coins[i - 1] >= 0)
                dp[i][j] = dp[i - 1][j] + dp[i][j - coins[i - 1]];
            else
                dp[i][j] = dp[i - 1][j];
        }
    }
    return dp[n][amount];
}
```

### 方法二：一维滚动数组
```cpp
int change(int amount, vector<int>& coins) {
    vector<unsigned int> dp(amount + 1, 0);
    dp[0] = 1;
    for(int i = 0; i < coins.size(); i++) {
        for(int j = coins[i]; j <= amount; j++) {  // 正序！完全背包
            dp[j] += dp[j - coins[i]];
        }
    }
    return dp[amount];
}
```

**数据类型坑点**：
- `int`：中间值溢出变负数 → WA
- `long long`：中间值超 2^63 → UBSan 报错 RE
- `unsigned int`：无符号溢出回绕是定义行为，最终答案 ≤ 2^31-1 时结果正确 → AC

## 下降路径最小和（931）
**二维网格DP**：从第一行任意列出发，每步可向正下/左下/右下移动，求到达最后一行的最小路径和

**状态定义**：`dp[i][j]` 表示从第一行下落到位置 `(i, j)` 的最小路径和

**状态转移**：`dp[i][j] = matrix[i][j] + min(dp[i-1][j-1], dp[i-1][j], dp[i-1][j+1])`

**DP table vs 备忘录的选择**：
- 状态是连续索引、转移逻辑清晰 → DP table（本题适用）
- 状态不规则、部分状态不会被访问 → 备忘录递归更灵活

```cpp
int minFallingPathSum(vector<vector<int>>& matrix) {
    int n = matrix.size();
    vector<vector<int>> dp(n, vector<int>(n));
    // base case：第一行直接取矩阵值
    for(int i = 0; i < n; i++) dp[0][i] = matrix[0][i];
    
    for(int i = 1; i < n; i++) {
        for(int j = 0; j < n; j++) {
            // 边界列用 INT_MAX 处理越界方向
            int left = (j > 0) ? dp[i-1][j-1] : INT_MAX;
            int mid = dp[i-1][j];
            int right = (j < n-1) ? dp[i-1][j+1] : INT_MAX;
            dp[i][j] = matrix[i][j] + min({left, mid, right});
        }
    }
    // 结果：最后一行所有列取最小
    int res = INT_MAX;
    for(int i = 0; i < n; i++) res = min(res, dp[n-1][i]);
    return res;
}
```

## 编辑距离（72）
**经典二维字符串DP**：将 word1 转换为 word2 的最少操作次数（插入/删除/替换）

**状态定义**：`dp[i][j]` 表示 `word1[0..i-1]` 转换为 `word2[0..j-1]` 的最小编辑距离

**状态转移**：
- 字符相同：`dp[i][j] = dp[i-1][j-1]`（跳过）
- 字符不同：三种操作取最小
  - 替换：`dp[i-1][j-1] + 1`
  - 删除：`dp[i-1][j] + 1`
  - 插入：`dp[i][j-1] + 1`

**base case**：`dp[i][0] = i`（word2为空，全删除）、`dp[0][j] = j`（word1为空，全插入）

### 方法一：迭代解法（自底向上）
```cpp
int minDistance(string word1, string word2) {
    int m = word1.size(), n = word2.size();
    vector<vector<int>> dp(m + 1, vector<int>(n + 1));
    // base case
    for(int i = 1; i <= m; i++) dp[i][0] = i;
    for(int j = 1; j <= n; j++) dp[0][j] = j;
    
    for(int i = 1; i <= m; i++) {
        for(int j = 1; j <= n; j++) {
            if(word1[i-1] == word2[j-1]) {
                dp[i][j] = dp[i-1][j-1];  // 字符相同，跳过
            } else {
                dp[i][j] = min({
                    dp[i-1][j-1] + 1,  // 替换
                    dp[i-1][j] + 1,     // 删除
                    dp[i][j-1] + 1,     // 插入
                });
            }
        }
    }
    return dp[m][n];
}
```

## 顺序任务分批 DP（批长代价 + 新批次固定代价）

**适用信号**：
- 任务顺序固定，不能重排；
- 需要把前 N 个任务划分为若干连续批次；
- 每批代价只与批长 L 有关，且从第二批开始有固定开销 X。

**通用步骤**：
1. 先预处理 `cost[L]`：一次处理长度为 L 的最小代价（可再套一层 `min` 选工具/策略）。
2. 定义 `dp[i]`：完成前 i 个任务的最小代价。
3. 初始化 `dp[i] = cost[i]`（不分批一次做完）。
4. 枚举切分点 `j`：
    `dp[i] = min(dp[i], dp[j] + dp[i-j] + X)`。

**复杂度**：
- 若 `cost` 预处理为 O(NM)，DP 为 O(N^2)，总计 O(NM + N^2)。

**通用坑点**：
- 第一批没有新增开销，别在初始化时多加 `X`；
- 转移时注意 `long long` 防止乘法溢出；
- 若状态可对称（`j` 与 `i-j`），可只枚举一半做常数优化。

**题目差异（P16229 外卖配送）**：
- `cost[L] = min_i(L*A_i + L*(L-1)/2*B_i)`，先按批长做“选工具最优”。
- 再做分批 DP，新增批次统一加 `X`，得到最终最小总耗时。

## 最后一块石头的重量 II（1049）
**问题转化**：两两碰撞后剩余最小 → 把石头分成两堆，使差值最小 → 一堆尽量接近 sum/2

**状态定义**：`dp[j]` 表示容量为 j 的背包最多能装多重的石头

**状态转移**：`dp[j] = max(dp[j], dp[j - stones[i]] + stones[i])`

```cpp
int lastStoneWeightII(vector<int>& stones) {
    int sum = 0;
    for(int num : stones) sum += num;
    int target = sum / 2;
    vector<int> dp(target + 1, 0);
    for(int i = 0; i < stones.size(); i++) {
        for(int j = target; j >= stones[i]; j--) {  // 0-1背包倒序
            dp[j] = max(dp[j], dp[j - stones[i]] + stones[i]);
        }
    }
    return (sum - dp[target]) - dp[target];  // 两堆之差
}
```

## 目标和（494）
**问题转化**：加减号分配 → 正数和 P、负数绝对值和 N → P=(sum+target)/2 → 装满容量 P 的方案数

**状态定义**：`dp[j]` 表示装满容量 j 的背包有几种方法

**状态转移**：`dp[j] = dp[j] + dp[j - nums[i]]`（0-1背包计数型）

```cpp
int findTargetSumWays(vector<int>& nums, int target) {
    int sum = 0;
    for(int num : nums) sum += num;
    if(abs(target) > sum) return 0;
    if((sum + target) % 2 != 0) return 0;  // 必须为偶数
    int P = (sum + target) / 2;
    vector<int> dp(P + 1, 0);
    dp[0] = 1;  // 装满容量0有1种方法（啥也不装）
    for(int i = 0; i < nums.size(); i++) {
        for(int j = P; j >= nums[i]; j--) {
            dp[j] = dp[j] + dp[j - nums[i]];
        }
    }
    return dp[P];
}
```

**坑点**：(sum+target) 为奇数时无解；|target| > sum 时无解；dp[0]=1 而非 0

## 一和零（474）
**二维费用 0-1 背包**：每个字符串有 0 的个数和 1 的个数两个"费用"

**状态定义**：`dp[j][k]` 表示最多 j 个 0 和 k 个 1 的最大子集长度

**状态转移**：`dp[j][k] = max(dp[j][k], dp[j-cnt0][k-cnt1] + 1)`

```cpp
int findMaxForm(vector<string>& strs, int m, int n) {
    vector<vector<int>> dp(m + 1, vector<int>(n + 1, 0));
    for(const string& str : strs) {
        int cnt0 = 0, cnt1 = 0;
        for(char s : str) {
            if(s == '0') cnt0++;
            else cnt1++;
        }
        for(int j = m; j >= cnt0; j--) {      // 两个维度都倒序
            for(int k = n; k >= cnt1; k--) {
                dp[j][k] = max(dp[j][k], dp[j - cnt0][k - cnt1] + 1);
            }
        }
    }
    return dp[m][n];
}
```

**坑点**：两个容量维度都必须倒序遍历；先统计每个字符串的 0/1 个数再做背包

## 单词拆分（139）
**完全背包变体**：字符串匹配，dp[i] 表示 s[0..i-1] 能否被拆分

**状态转移**：`dp[i] = dp[i] || (dp[i-len] && s.substr(i-len, len) == word)`

```cpp
bool wordBreak(string s, vector<string>& wordDict) {
    vector<bool> dp(s.length() + 1, false);
    dp[0] = true;
    for(int i = 1; i <= s.length(); i++) {
        for(const string& word : wordDict) {
            int len = word.length();
            if(i >= len && dp[i - len] && s.substr(i - len, len) == word) {
                dp[i] = true;
                break;  // 找到一个即可
            }
        }
    }
    return dp[s.length()];
}
```

## 完全平方数（279）
**完全背包最值型**：物品是 1,4,9,16,... 的完全平方数，求凑出 n 的最少个数

**状态转移**：`dp[i] = min(dp[i], dp[i - j*j] + 1)`

```cpp
int numSquares(int n) {
    vector<int> dp(n + 1, INT_MAX);
    dp[0] = 0;
    for(int i = 1; i <= n; i++) {         // 遍历背包
        for(int j = 1; j * j <= i; j++) { // 遍历物品
            dp[i] = min(dp[i], dp[i - j * j] + 1);
        }
    }
    return dp[n];
}
```

**坑点**：因为不是求排列，两个循环顺序可颠倒；初始化 INT_MAX 需防 dp[i - j*j] + 1 溢出

## 组合总和 Ⅳ（377）
**完全背包排列数**：求凑出 target 的排列个数（{1,2} 和 {2,1} 算两种）

**状态转移**：`dp[i] += dp[i - nums[j]]`（外层遍历背包、内层遍历物品）

```cpp
int combinationSum4(vector<int>& nums, int target) {
    vector<unsigned long long> dp(target + 1, 0);
    dp[0] = 1;
    for(int i = 1; i <= target; i++) {       // 外层遍历背包
        for(int j = 0; j < nums.size(); j++) { // 内层遍历物品
            if(i >= nums[j]) dp[i] += dp[i - nums[j]];
        }
    }
    return dp[target];
}
```

**坑点**：与 518（组合数）循环顺序相反——求排列先循环背包再循环物品；数据类型用 unsigned long long 防溢出

## 多重背包（二进制拆分）

**多重背包**：每种物品有数量上限 k[i]，不能无限选也不能只选一件。

### 朴素做法
在 0/1 背包基础上，对每种物品多加一层遍历 k[i] 次的循环。时间 O(C * N * max(k[i]))，数量大时超时。

### 二进制拆分（推荐）
**核心思想**：将每类物品按 1,2,4,...,2^n 拆分，剩余尾数单独成件。拆分后每件视为独立 0/1 物品，跑标准 0/1 背包。

**适用信号**：物品有数量上限，且朴素做法三层循环会超时。

**通用步骤**：
1. 对每类物品 i，按 k=1,2,4,... 拆分，每件重量=w[i]*k，价值=v[i]*k，同时 n[i] -= k
2. 若 n[i] > 0，剩余尾数单独成件
3. 对所有拆分后的物品跑一维 0/1 背包（倒序遍历容量）

**正确性**：二进制拆分保证 [0, k[i]] 的每个数量都能由若干拆分件组合得到。

**复杂度**：拆分件数 O(sum log k[i])，总体 O(C * sum log k[i])，空间 O(C)。

**坑点**：容量必须倒序更新；拆分时要正确扣减剩余数量，尾数不能漏。

```cpp
// 二进制拆分
vector<int> weight, value;
for(int i = 0; i < N; i++) {
    for(int k = 1; k <= n[i]; k <<= 1) {
        weight.push_back(w[i] * k);
        value.push_back(v[i] * k);
        n[i] -= k;
    }
    if(n[i] > 0) {
        weight.push_back(w[i] * n[i]);
        value.push_back(v[i] * n[i]);
    }
}
// 标准 0-1 背包
vector<int> dp(C+1, 0);
for(int i = 0; i < (int)weight.size(); i++) {
    for(int j = C; j >= weight[i]; j--) {
        dp[j] = max(dp[j], dp[j - weight[i]] + value[i]);
    }
}
```

## 题型模板：带冷却时间的 0/1 背包（时间轴背包）
**适用信号**：物品分布在时间轴上，选取有"间隔 >= K"约束，同时有总预算/容量上限

**通用步骤**：
1. 将时间离散化（如日期映射到 1~365）
2. 按时间汇总物品（同一时间点可能有多个物品）
3. `dp[time][budget]` 维护前 `time` 个时间单位、预算不超 `budget` 的最大收益
4. 转移：不选当前时间 → `dp[time][budget] = dp[time-1][budget]`；选当前时间某物品 → `dp[max(0,time-K)][budget-v] + v`

**复杂度**：O(T * M)，T 为时间范围，M 为预算上限

**通用坑点**：
- 间隔约束用 `dp[time-K]` 而非 `dp[time-1]`
- 同一时间点可能有多个物品，需遍历取最优
- `prev_time = max(0, time-K)` 处理边界

### 费用报销（蓝桥杯 2195）
**相对模板的变化**：时间轴为 1~365 天（非闰年），同一张日期可能有多张票据

```cpp
// 月/日映射到绝对天数

        int prev_day = max(0, i - K);

    }
}
```

## 题型模板：承重/堆叠约束的 0/1 背包（排序+背包）
**适用信号**：物品有"承重"和"价值"双重属性，堆叠/排列时上方总重不能超过下方物品的承重能力（即价值）

**通用步骤**：
1. 按 `w + v` 排序（保证处理当前物品时，已选物品总重不超过其价值）
2. `dp[totalWeight]` 维护总重量为 `totalWeight` 的最大价值
3. 0/1 背包倒序遍历，上界用当前物品的 `w + v`（不是全局常量）
4. 答案取所有 `dp[j]` 的最大值

**复杂度**：O(n * Wmax)，Wmax 为可达最大总重量

**通用坑点**：
- 必须按 `w + v` 排序，不能按 `w` 或 `v` 单独排序
- 转移上界是当前物品的 `w + v`，不是全局容量
- 答案是所有 `dp[j]` 的最大值，不是某个固定位置
- 必须倒序更新 dp，否则重复使用同一物品

### 搬砖（蓝桥杯 2201）
**相对模板的变化**：w_i <= 20, v_i <= 20000，故 Wmax <= 20020

```cpp
// 按 w+v 排序
sort(v.begin(), v.end(), [](auto& a, auto& b) {
    return a.first + a.second < b.first + b.second;
});
const int MAX_W = 20050;
vector<int> dp(MAX_W, 0);
for(int i = 0; i < n; i++) {
    int w = v[i].first, value = v[i].second;
    // 上界：w + value（该砖最多承受的总重量）
    for(int j = w + value; j >= w; j--) {
        dp[j] = max(dp[j], dp[j - w] + value);
    }
}
// 答案取全局最大值
int ans = *max_element(dp.begin(), dp.end());
```
