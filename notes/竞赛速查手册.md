## 场景速查：看到题目第一步怎么做

### "求区间和"
1. 有没有修改？**没有** → 前缀和，O(1) 查询
2. 有单点修改？ → 树状数组 / 线段树
3. 有区间修改？ → 树状数组（差分/双树）/ 线段树（lazy）

### "求最值"
1. 静态查询？ → ST表（O(1)查询）或 线段树
2. 有修改？ → 线段树
3. 滑动窗口最值？ → 单调队列（见 [栈与队列](./栈与队列.md)）或 multiset

### "求第k小 / 中位数"
1. 静态排序？ → 排序后直接取
2. 动态插入删除？ → 值域树状数组 + 二分，或 `pb_ds::ordered_set`
3. 栈 + 中位数？ → 栈维护顺序 + 值域树状数组（L3-002 模式）

### "子数组满足某条件"
1. 和 = k？ → 前缀和 + 哈希表计数
2. 和被k整除？ → 前缀和取模 + 哈希表
3. 最长/最短？ → 前缀和 + 哈希表存首次索引，或滑动窗口
4. 元素恒正？ → 滑动窗口 / 前缀和 + 二分

### "连通性 / 分组"
1. 动态加边？ → 并查集
2. 需要路径？ → DFS / BFS
3. 最小生成树？ → Kruskal（并查集）或 Prim

### "枚举所有方案"
1. 子集/排列/组合？ → 回溯
2. 状态数 ≤ 20？ → 状态压缩DP（位运算）
3. 选或不选？ → 背包 / DP

## 常见陷阱速查

| 陷阱 | 正确做法 | 详见 |
|------|---------|------|
| 浮点数判零 `== 0` | `abs(x) < EPS`（EPS = 1e-7） | [比赛注意事项](./比赛注意事项.md) |
| 负数取模 | `(x % k + k) % k` | [区间数据结构](./区间数据结构.md) |
| 树状数组 0-indexed | 必须 1-indexed | [区间数据结构](./区间数据结构.md) |
| 线段树数组开小 | 开 4 倍空间 | [区间数据结构](./区间数据结构.md) |
| `int` 溢出 | 用 `long long` | [比赛注意事项](./比赛注意事项.md) |
| `erase` 迭代器失效 | `it = s.erase(it)` | [set进阶](./set进阶.md) |
| multiset `erase(value)` 删全部 | `ms.erase(ms.find(value))` | [set进阶](./set进阶.md) |
| 忘记 `ios::sync_with_stdio(false)` | 每个文件开头加 | [比赛注意事项](./比赛注意事项.md) |
| STL 函数名拼错 | 对照 [STL速查表](./STL速查表.md) | |
