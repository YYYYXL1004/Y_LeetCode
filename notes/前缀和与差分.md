# 前缀和与差分

## 一维前缀和
- `preSum[i]` 存储 `nums[0..i-1]` 的和，O(1) 查询区间和
- 区间和：`sum(l, r) = preSum[r+1] - preSum[l]`
  ```cpp
  preSum.resize(nums.size() + 1);
  for(int i = 1; i < preSum.size(); i++)
      preSum[i] = preSum[i-1] + nums[i-1];
  // 查询 [left, right] 区间和
  return preSum[right+1] - preSum[left];
  ```

## 二维前缀和
- 构建：`preSum[i][j] = preSum[i-1][j] + preSum[i][j-1] + matrix[i-1][j-1] - preSum[i-1][j-1]`
- 查询：`sumRegion = preSum[x2+1][y2+1] - preSum[x1][y2+1] - preSum[x2+1][y1] + preSum[x1][y1]`

## 前缀积
- 除自身以外的乘积：左侧前缀积 × 右侧后缀积，可优化到 O(1) 空间
  ```cpp
  // O(1) 额外空间写法
  vector<int> ans(n, 1);
  int left = 1;
  for(int i = 0; i < n; i++) { ans[i] = left; left *= nums[i]; }
  int right = 1;
  for(int i = n-1; i >= 0; i--) { ans[i] *= right; right *= nums[i]; }
  ```

## 哈希表 + 前缀和

**题型模板：前缀和 + 哈希表求子数组问题**
- **适用信号**：题目要求统计/判断/最值某种"子数组和"的性质（等于k、被k整除、为0等）
- **核心公式**：子数组 `[i+1, j]` 的和 = `preSum[j] - preSum[i]`
- **通用步骤**：遍历数组维护前缀和 → 对前缀和做变换（取模/直接用/映射） → 哈希表查询匹配值 → 更新答案
- **两种存储策略**：
  - 计数类（统计个数）：存频次 `{值: 出现次数}`，每次累加匹配次数
  - 最值/存在性类（求长度/判断存在）：存首次索引 `{值: 最早下标}`，只在首次出现时记录
- **兜底初始化**：`preMap[0] = -1`（索引型）或 `preFreq[0] = 1`（频次型），处理子数组从头开始的情况
- **坑点**：C++ 负数取模需 `(preSum % k + k) % k` 修正

### 策略一：存频次（计数类）
```cpp
// 和为 K 的子数组（560）：直接用前缀和作 key
// 和可被 K 整除的子数组（974）：用余数作 key
unordered_map<int, int> preFreq;
preFreq[0] = 1; // 兜底
int preSum = 0, count = 0;
for (int i = 0; i < n; i++) {
    preSum += nums[i];
    int key = 变换(preSum); // 直接用 preSum，或 (preSum % k + k) % k
    if (preFreq.count(key)) count += preFreq[key];
    preFreq[key]++; // 每次都更新频次
}
```

### 策略二：存首次索引（最值/存在性类）
```cpp
// 连续子数组和（523）：余数相同 ⟹ 中间段和为 k 的倍数，判断长度 >= 2
// 连续数组（525）：将 0→-1, 1→1，求和为 0 的最长子数组
// 表现良好的最长时间段（1124）：>8h→+1, ≤8h→-1，求最长正和区间
unordered_map<int, int> preMap;
preMap[0] = -1; // 兜底
int preSum = 0, maxlen = 0;
for (int i = 0; i < n; i++) {
    preSum += 变换(nums[i]);
    int key = 变换(preSum);
    if (preMap.count(key))
        maxlen = max(maxlen, i - preMap[key]);
    if (!preMap.count(preSum))
        preMap[preSum] = i; // 只记录首次出现
}
```

### 题目差异
- **560（和为 K）**：直接用 `preSum` 作 key，查找 `preSum - k` 的频次
- **974（和可被 K 整除）**：用 `preSum % k` 作 key，负数取模需修正 `(x % k + k) % k`
- **523（连续子数组和）**：同余存在性，只记录首次索引，判断 `i - preMap[remainder] >= 2`
- **525（连续数组）**：`0→-1` 映射转化，求和为 0 的最长子数组
- **1124（表现良好的最长时间段）**：`>8h→+1` 映射转化，找 `preSum - 1` 的首次出现位置（最容易满足 > 0）

### 原始代码参考
```cpp
// 连续子数组和（523）：前缀和取模 + 哈希表记录首次出现位置
unordered_map<int, int> valToIndex;
for(int i = 0; i <= n; i++) {
    int val = preSum[i] % k;
    if(!valToIndex.count(val)) valToIndex[val] = i;
}
// 连续数组（525）：将 0 视为 -1，转化为找和为 0 的最长子数组
preSum[i] = preSum[i-1] + (nums[i-1] == 0 ? -1 : 1);
```

## 差分数组
- 差分是前缀和的逆运算，适合处理**区间增减**问题
- `diff[i]` 表示 `nums[i] - nums[i-1]`
- 对区间 `[l, r]` 加 val：`diff[l] += val`，`diff[r+1] -= val`
- 通过前缀和还原原数组
- 注意区间是 `[l, r]` 还是 `[l, r)`，决定减的位置是 `r+1` 还是 `r`
  ```cpp
  // 拼车（1094）：to 站已下车，所以是 diff[to] -= val 而非 diff[to+1]
  diff[from] += numPassengers;
  diff[to] -= numPassengers;
  ```
- 差分数组必须按顺序累加才能得到正确结果
