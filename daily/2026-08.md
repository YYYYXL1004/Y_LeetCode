# 2026年8月 学习记录

## 8.27
- 二叉树递归遍历与结构修改专题：完成 2 道 LeetCode，分别练习节点身份判定和在指定深度修改树结构
  - 题型模板（可迁移）：在遍历中判定特定节点
    - 适用信号：题目要求统计满足“方向 + 结构”条件的节点，例如左叶子、特定深度叶子
    - 通用步骤：递归访问当前节点时，通过父节点的孩子指针判断目标节点；满足条件后更新外部答案，再继续遍历左右子树
    - 复杂度：每个节点访问一次，时间 O(n)，递归栈空间 O(h)
    - 坑点：左叶子必须同时满足“是父节点的左孩子”和“自身没有左右孩子”，不能把所有左孩子都计入
  - 题型模板（可迁移）：在指定深度修改二叉树结构
    - 适用信号：需要在某一层统一插入、删除或替换节点，同时保留原有子树
    - 通用步骤：遍历到目标层的上一层后创建新节点；先保存或接管原孩子，再把新节点挂回父节点；根节点特判
    - 复杂度：最坏访问整棵树，时间 O(n)，递归栈空间 O(h)
    - 坑点：左右原子树的接法不同；插入完成后要避免再次把新节点当成目标父节点重复修改
  - 404：左叶子之和，DFS 前序遍历 + 叶子节点判定
    - 核心思路：在当前节点处检查左孩子是否存在且为叶子，满足时累加左孩子的值，再递归遍历左右子树
    - 坑点：单节点根不是左叶子；判断对象应为 `root->left`，并同时检查其左右孩子为空
  - 623：在二叉树中增加一行，DFS + 指定深度结构修改
    - 核心思路：遍历到 `depth - 1` 层，为每个节点创建两个值为 `val` 的新孩子；原左子树接到新左节点的左侧，原右子树接到新右节点的右侧
    - 坑点：`depth == 1` 时需要新建根并把原树接为左子树；递归深度要成对加减，避免层数状态污染
